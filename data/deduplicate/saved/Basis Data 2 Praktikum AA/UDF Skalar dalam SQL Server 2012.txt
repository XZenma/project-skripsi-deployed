Fungsi adalah blok kode yang dapat dipanggil
berulang kali untuk melakukan tugas tertentu
User Defined Function (UDF) adalah fungsi yang
dibuat oleh pengguna sesuai kebutuhan
Fungsi selalu mengembalikan nilai (return value)
Keuntungan: modularitas, reusability, kemudahan
maintenance
Pengertian Fungsi (UDF)
Jenis-Jenis Function di SQL Server
Scalar Function: mengembalikan satu nilai
tunggal dengan tipe data tertentu (contoh:
INT, VARCHAR, DATE). Fokus utama modul ini.
Inline Table Valued Function: mengembalikan
tabel (Inline TVF dari satu SELECT, Multi
Statement TVF dari beberapa statement).
Multi Statement Table Valued Function:
fungsi ini memberikan hasil keluaran berupa
tabel dimana hasil dari query itu dimasukkan
ke dalam variabel dengan tipe data tabel
Fungsi yang mengembalikan satu
nilai dengan tipe data spesifik
Ciri utama: menghasilkan single
value, bukan tabel
Dapat digunakan dalam SELECT,
WHERE, atau ekspresi lainnya
Fokus: Scalar Function
Struktur Dasar Function
CREATE FUNCTION nama_fungsi (@param TIPE_DATA)
RETURNS TIPE_RETURN
AS
BEGIN
DECLARE @hasil TIPE_RETURN;
SET @hasil = [Nilai atau Ekspresi];
RETURN @hasil;
END
GO
select dbo.<nama_fungsi>
