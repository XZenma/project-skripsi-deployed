Deleted table inserted table
Jika kita melakukan operasi DML ( insert update delete ) pada suatu
tabel, maka secara otomatis akan terbentuk tabel virtual INSERTED
dan DELETED.
Misalkan kita memiliki tabel Mahasiswa ,maka jika melakukan operasi
DML , maka akan terbentuk secara otomatis tabel virtual INSERTED
dan tabel virtual DELETED yang sesuai dengan struktur tabel
mahasiswa . Tabel INSERTED dan DELETED ini akan berisi data-data
yang ditambahkan , dirubah atau dihapus pada tabel Mahasiswa.
Deleted table inserted table
Jika kita melakukan operasi insert, maka tabel inserted berisi data
yang baru , yang ditambahkan.
Jika kita melakukan operasi delete, maka tabel deleted berisi data
lama , yang telah dihapus
Jika kita melakukan operasi update, maka tabel deleted berisi data
lama yang telah dirubah, dan tabel inserted beri data baru yang telah
dimasukkan.

TRIGGER
Definisi :
Sekumpulan baris-baris kode program yang dijalankan akibat dari
adanya aksi user atau event tertentu.
Trigger for insert on <tablename>
Kode program yang dijalankan akibat adanya aksi insert pada table
<tablename>
Trigger for update on <tablename>
Kode program yang dijalankan akibat adanya aksi update pada table
<tablename>
TRIGGER
Trigger for delete on <tablename>
Kode program yang dijalankan akibat adanya aksi delete pada table
<tablename>
Manfaat trigger
1. Trigger merupakan salah satu mekanisme untuk menjalankan aturan
bisnis dan menjaga integritas data dalam sebuah basis data.
Mekanisme yang lainnya adalah penggunaan CONSTRAINT
2. Trigger dapat mengevaluasi status dari sebuah tabel sebelum dan
sesudah terjadi perubahan data dan melakukan aksinya sesuai
perbedaan yang terjadi
Contoh
Kita hendak membuat trigger untuk mencegah user memasukkan nilai
negatif pada kolom harga di tabel makanan
Trigger for insert on makanan ( check constraint)
Use ISA212_LAB
Go
Use makanan
go
Create trigger dbo.tr_insert_harga on makanan for insert
As
Begin
declare @harga_new integer
select @harga_new = ins.harga from inserted ins
if @harga_new<0 then
begin
rollback
print 'harga makanan yang anda masukkan adalah negatif,
sehingga operasi insert dibatalkan'
End
end
Trigger for update on makanan ( check constraint)
Use ISA212_LAB
Go
Use makanan
go
Create trigger dbo.tr_update_harga on makanan for update
As
Begin
declare @harga_new integer
declare @harga_old integer
select @harga_new = ins.harga from inserted ins
select @harga_old = del.harga from deleted del
if @harga_new<0 then
begin
rollback
print 'harga makanan yang anda masukkan adalah
negatif,
sehingga operasi update dibatalkan'
End
end

Database akademik
Sebelumnya sudah dibuat oleh para mahasiswa basisdata akademik1,
yang berisi dua tabel, yaitu tabel mahasiswa dan tabel wali:
Melacak perubahan isi tabel dengan trigger
1. Jika user memasukkan baris baru pada tabel wali , maka akan
dimasukkan baris baru di tabel wali_audit.
2. Baris baru di tabel wali_audit berisi, keterangan id_wali yang
ditambahkan , ditambah informasi waktu dan jam baris baru ini
ditambahkan.
3. Untuk bisa mewujudkan nomor 1 dan nomor 2, kita buat dulu tabel
wali_audit
Tabel wali_audit
Create wali_audit
(no int identity(1,1), keterangan_audit varchar(100))
Membuat trigger insert dan mengisi table wali_audit
use akademik1
Go
Create trigger dbo.tr_insert_wali for insert on wali
As
Begin
Declare @id int
Select @id =id_wali from inserted
Insert into wali_audit
Values (' wali baru dengan id=' + cast (@id as nvarchar(5)) +
'ditambahkan pada '+ cast (getdate() as nvarchar(20)
End
Kalimat insert pada tabel wali
Insert into wali (id_wali , nama_wali)
values (5, 'Corry Caromawati')
Go
Select * from wali
Select * from wali_audit
Membuat trigger update dan mengisi table wali_audit

Go
