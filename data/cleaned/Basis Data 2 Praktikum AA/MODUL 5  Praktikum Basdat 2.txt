Store procedure
Praktikum ISB 212 - Basisdata | Modul 5
Apa itu store procedure?
Store procedure merupakan kumpulan perintah yang disimpan
dengan nama tertentu dan diproses sebagai satu kesatuan.
Procedure ini dapat menerima input, menghasilkan output, berisi
satu atau lebih operasi database, serta bisa memanggil
procedure lain, dengan hasil berupa status berhasil atau gagal.
Keuntungan Menggunakan Store Procedure
Portabilitas: Bisa digunakan oleh berbagai aplikasi karena tersimpan di
server database
Performa lebih cepat: Diproses di server sehingga tidak membebani client
Keamanan lebih baik: Business logic tersimpan di server dan dapat
dienkripsi sehingga tidak mudah diakses pengguna

Stored Procedure dengan Parameter Output
CREATE PROCEDURE dbo.sp_total_customer
@total_customer INT OUTPUT
AS
BEGIN
SELECT @total_customer = COUNT(*)
FROM customers
END
GO
DECLARE @hasil INT
EXEC dbo.sp_total_customer @hasil OUTPUT
SELECT @hasil AS Total_Customer
Menghitung total customer

Satu variabel input dan satu variabel output
CREATE PROCEDURE dbo.sp_kota_customer
@id_customer INT,
@kota VARCHAR(25) OUTPUT
AS
BEGIN
SELECT @kota = city
FROM customers
WHERE customer_id = @id_customer
END
GO
DECLARE @hasil VARCHAR(25)
EXEC dbo.sp_kota_customer 3, @hasil OUTPUT
SELECT @hasil AS Kota
Menampilkan kota customer bedasarkan ID.
